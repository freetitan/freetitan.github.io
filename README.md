## 三大研究方向

1. **政策试点、优化与评估（算法与代码）** — 强化学习与贝叶斯实验
2. **政策文件中的制度语法（编码与机器学习）** — 结构化文本与自然语言处理
3. **中国的科技人才政策（理论与实证研究）** — 科技创新的权威与激励机制
